# Jazmin's Birthday Website

## Folder structure

jazmins-birthday-website/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    └── (put your images here)

## How to use

Open `index.html` in a browser.

### Adding images

Put your images inside `assets/`, then reference them from HTML/CSS like:

HTML:
<img src="assets/my-photo.jpg" alt="Description">

CSS:
background-image: url("../assets/my-photo.jpg");

### Main files

- `index.html` = the page content/sections
- `css/style.css` = all styling, layout, fonts and responsive design
- `js/script.js` = menu, FAQ accordions and sticky ticket button
- `assets/` = photos, logos and other images

Replace the `#` on the ticket button in `index.html` with your real payment/ticket link.
